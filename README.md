# TP VDE
Plusieurs simulations vous seront proposées, structurées en modules progressifs couvrant l’ensemble du parcours, des fondamentaux jusqu’à l’administration système.

Pré-requis :

•	Avoir suivi le cours “Administrez un système Linux”.

•	Ou maîtriser les bases d’un système Linux et être à l’aise avec la ligne de commande.

Outils nécessaires :

•	VirtualBox / Vmware

A la fin du module, un QCM de révision généraliste et un cas pratique complet portant sur un scénario réel : 
Déployer un serveur de sauvegarde automatisé, sécurisé et planifié.
